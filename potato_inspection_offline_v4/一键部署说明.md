# 一键部署说明

## 快速部署（只需两步）

### 步骤1：运行部署脚本
```powershell
cd F:\seven\seven_plc_vision_app
.\deploy.ps1
```

部署脚本会自动：
- ✅ 检查Python环境
- ✅ 创建虚拟环境
- ✅ **自动安装所有依赖包**（即使没有requirements.txt也会安装）
  - ultralytics==8.3.222
  - opencv-python==4.10.0.84
  - numpy>=1.24.0
  - Pillow>=10.0.0
- ✅ 验证模型文件
- ✅ 创建输出目录

### 步骤2：运行检测服务
```powershell
.\run_detection_service.ps1 -CameraDir "F:\data\camera" -PLCIp "192.168.1.1" -PLCPort 502 -Channels "1,2,3,4"
```

## 如果遇到问题

### 问题1：requirements.txt not found
**解决方案**：不用担心！部署脚本会自动安装所有必要的依赖包，即使没有requirements.txt文件。

### 问题2：ModuleNotFoundError: No module named 'cv2'
**解决方案**：重新运行部署脚本，确保依赖安装完成：
```powershell
.\deploy.ps1
```

### 问题3：虚拟环境已存在但缺少依赖
**解决方案**：删除虚拟环境后重新部署：
```powershell
Remove-Item -Recurse -Force venv
.\deploy.ps1
```

```powershell
# 1. 进入项目目录

```

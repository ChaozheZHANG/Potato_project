# 如何查看检测结果

## ✅ 服务已成功启动！

从您的输出可以看到：
- ✅ 检测服务已启动
- ✅ PLC已连接成功 (`[plc] Connected to 192.168.1.1:502`)
- ✅ 正在监控相机目录 `F:\data\camera`

## 🔄 工作流程

1. **相机拍照** → `cam_plc_capture.py` 拍照并保存到 `F:\data\camera\YYYYMMDD\CH{CC}_{YYYYMMDD}_{HHMMSS}-{N}.jpg`
2. **检测服务监控** → `detect_and_write_plc.py` 检测到新图片
3. **自动检测** → 对图片中的土豆进行检测和分级
4. **写入PLC** → 将分级结果写入PLC寄存器
5. **控制台输出** → 实时显示检测结果

## 📊 查看结果的方法

### 方法1：控制台实时输出（最直观）

当检测到土豆时，控制台会显示：

```
[→] ch1 | CH01_20251112_121608-001.jpg | 检测到 3 个土豆，开始分级...
[✓] ch1 | CH01_20251112_121608-001.jpg | Grade: OK_S3 | PLC值: 3 | 地址: 508 | 写入成功
   检测到 3 个土豆，主要结果: OK_S3 (面积: 125000px)
```

**输出说明**：
- `[→]` = 正在处理
- `[✓]` = 成功（检测完成并写入PLC）
- `[✗]` = 失败
- `[!]` = 警告（如未检测到土豆）

### 方法2：查看PLC寄存器值

使用 `plc_dummy_loop.py` 或PLC监控软件查看寄存器值：

**寄存器地址**（根据通道）：
- 通道1: 地址 `508` (C1_ATTRS_BASE)
- 通道2: 地址 `572` (C2_ATTRS_BASE)
- 通道3: 地址 `636` (C3_ATTRS_BASE)
- 通道4: 地址 `700` (C4_ATTRS_BASE)

**PLC值含义**：
- `1` = OK_S1 (最小尺寸合格品)
- `2` = OK_S2
- `3` = OK_S3
- `4` = OK_S4
- `5` = OK_S5
- `6` = OK_S6
- `7` = OK_S7 (最大尺寸合格品)
- `8` = NG (不合格品)

### 方法3：查看本地日志文件（如果启用）

检测服务会在控制台实时输出，如果需要保存日志，可以重定向输出：

```powershell
.\run_detection_service.ps1 -CameraDir "F:\data\camera" -PLCIp "192.168.1.1" -PLCPort 502 -Channels "1,2,3,4" | Tee-Object -FilePath "detection_log.txt"
```

## 🎯 测试步骤

1. **确保相机服务运行**：
   ```powershell
   # 在另一个PowerShell窗口运行
   python -m app.cam_plc_capture --fps 5 --threshold 10 --dim-n 1 --tcp 192.168.10.7:10000 --raw-file config\light_on.txt --read-reply --plc-ip 192.168.1.1 --plc-port 502 --channels 1,2,3,4 --addr-base 0 --out F:/data/camera
   ```

2. **确保检测服务运行**（您已经启动了）：
   ```powershell
   .\run_detection_service.ps1 -CameraDir "F:\data\camera" -PLCIp "192.168.1.1" -PLCPort 502 -Channels "1,2,3,4"
   ```

3. **让土豆通过相机** → 系统会自动：
   - 检测新图片
   - 识别土豆
   - 分级
   - 写入PLC
   - 在控制台显示结果

## 📝 示例输出

当有土豆通过时，您会看到类似这样的输出：

```
[→] ch1 | CH01_20251112_121608-001.jpg | 检测到 3 个土豆，开始分级...
[✓] ch1 | CH01_20251112_121608-001.jpg | Grade: OK_S3 | PLC值: 3 | 地址: 508 | 写入成功
   检测到 3 个土豆，主要结果: OK_S3 (面积: 125000px)

[→] ch2 | CH02_20251112_121610-001.jpg | 检测到 1 个土豆，开始分级...
[✓] ch2 | CH02_20251112_121610-001.jpg | Grade: NG | PLC值: 8 | 地址: 572 | 写入成功
   检测到 1 个土豆，主要结果: NG (面积: 95000px)
```

## ⚠️ 注意事项

1. **图片格式**：确保图片文件名格式为 `CH{CC}_{YYYYMMDD}_{HHMMSS}-{N}.jpg`
2. **扫描间隔**：默认每0.5秒扫描一次，如果图片生成很快，可能需要调整
3. **PLC连接**：如果PLC断开，服务会尝试自动重连
4. **未检测到土豆**：如果图片中没有土豆，会显示 `[!] 未检测到土豆`

## 🔍 故障排查

### 问题：没有看到检测输出

**检查**：
1. 相机服务是否在运行并保存图片？
2. 图片是否保存到正确的目录？
3. 图片文件名格式是否正确？

### 问题：PLC写入失败

**检查**：
1. PLC IP和端口是否正确？
2. 网络连接是否正常？
3. 查看控制台的错误信息


当土豆通过相机时，控制台会实时显示检测结果，同时结果也会写入到PLC寄存器。

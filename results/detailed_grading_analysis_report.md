**关键发现**:

## 推荐方案详细说明

### 方案C优势分析

1. **准确率最高**: 100%的准确率，与方案A相当
2. **重叠率合理**: 平均23.7%的重叠率在可接受范围内
3. **实施简单**: 仅需视觉估重，无需额外传感器
4. **符合行业标准**: 50g跨度是土豆分级常用规格
5. **成本效益高**: 实施成本低，维护简单

### 潜在问题与解决方案

#### 问题1: 边界样本误判
**现象**: Level 2-3边界重叠率37.5%，Level 3-4边界重叠率35.7%
**解决方案**:
- 实施±5g缓冲区策略
- 多角度/多帧验证
- 人工复核机制

#### 问题2: 密度差异影响
**现象**: 土豆密度差异导致体积相同但重量不同
**解决方案**:
```python
# 密度校准算法
def calibrate_weight(visual_volume, shape_feature):
    base_density = 1.10  # 标准密度 g/cm³
    
    # 基于形状调整密度
    if circularity > 0.85:
        density = 1.12  # 圆形土豆密度较高
    elif circularity < 0.70:
        density = 1.08  # 不规则土豆密度较低
    else:
        density = base_density
    
    return visual_volume * density
```

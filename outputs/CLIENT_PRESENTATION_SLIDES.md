## Slide 8: 方案A - Excel方案

```
📋 方案描述
  分级依据: 重量 + 长度/直径双标准
  数据来源: 现场实测Excel表格

✓ 优势
  • 准确性高（双维度验证）
  • 与人工经验一致

✗ 劣势
  • 需要双传感器（成本高）
  • 尺寸测量误差大（不规则形状）
  • 处理时间长（影响节拍）
  • 尺寸与重量不完全对应

📊 数据分析
┌─────────────────────────────┐

│ 视觉可区分性: ⭐⭐           │

└─────────────────────────────┘
```

## Slide 14: 潜在问题与解决方案

```
⚠️ 问题1: 密度差异影响

  问题: 高密度土豆可能被判低一级
  
  解决: ✓ 密度校准算法（基于形状特征）
       ✓ 圆形度 → 高密度
       ✓ 椭圆形 → 低密度
       ✓ 误差控制在 ±5%


⚠️ 问题2: 边界样本误判

  问题: 249g vs 251g 难区分
  
  解决: ✓ 边界模糊化（±5g缓冲区）
       ✓ 多角度/多帧验证
       ✓ 人工复核机制（可选）


⚠️ 问题3: Level 7 跨度大

  问题: 150-250g 是否太宽？
  
  解决: ✓ 小型土豆市场价值低，精度要求不高
       ✓ 客户可选择拆分（150-200, 200-250）
       ✓ 灵活配置
```

## Slide 20: Q&A

```
❓ 常见问题

Q1: 为什么不用称重传感器？
A: 成本高、影响节拍、维护复杂。
   视觉估重准确率可达90%+。

Q2: 如果客户要求更高精度怎么办？
A: 可以缩小重量跨度（如25g）
   或增加验证环节。

Q3: 不同品种土豆密度差异大怎么办？
A: 密度校准算法可以处理，
   必要时为特定品种重新校准。

Q4: 如何保证NG品不流出？
A: NG召回率目标≥98%，
   宁可误判OK为NG，不让NG流出。

Q5: 系统部署需要多久？
A: 预计11月底完成部署和验收
   （6周总工期）。
```

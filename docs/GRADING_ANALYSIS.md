## 方案A：Excel方案（重量+尺寸双标准）

### 方案描述
- **分级依据**: 重量 + 长度/直径测量
- **数据来源**: 现场实测Excel表格
- **样本量**: 约300-500个

### 分级规则示例
```
Level 1: 重量 500-550g AND (长度 > 15cm OR 直径 > 8cm)
Level 2: 重量 450-500g AND (长度 12-15cm OR 直径 7-8cm)
...
```

### 优势
✓ 准确性高（双维度验证）  
✓ 与人工分级经验一致  
✓ 减少边界误判

### 劣势
✗ 需要双传感器（相机+称重）  
✗ 尺寸测量误差大（土豆不规则）  
✗ 实施成本高  
✗ 尺寸与重量不完全对应（密度差异）  
✗ 处理时间长，影响节拍

### 数据分析
```
级间重叠率分析（基于Excel数据）:
Level 1-2: 12% 重叠（重量一致但尺寸不同）
Level 2-3: 15% 重叠
Level 6-7: 8% 重叠

结论: 尺寸作为辅助标准会引入额外复杂度
```

## 方案B：第一批方案（体积人工划分）

### 方案描述
- **分级依据**: 视觉估算体积
- **数据来源**: 人工经验划分
- **样本量**: 约200个（1-8级OK品 + 9级NG品）

### 分级规则
```
Level 1: 视觉判断"特大"
Level 2: 视觉判断"大"
Level 3-5: 视觉判断"中"
Level 6-7: 视觉判断"小"
Level 9: NG品
```

### 优势
✓ 实施简单  
✓ 符合人工分拣直觉

### 劣势
✗ **关键问题**: 同一级内重量跨多级  
  - 例如: Level 3 包含了 300-500g 的土豆  
✗ 与客户重量标准不符  
✗ 训练数据标注混乱  
✗ 无法满足精确控重需求

### 数据分析
```
实际称重后发现的问题:
Level 3 (标注为"中型"):
  - 最轻: 280g → 应为 Level 6
  - 最重: 520g → 应为 Level 1
  - 跨度: 240g (跨越4-5个正确等级)

结论: 此方案不可用，需要完全重新标注
```

## 方案C：第二批方案（50g重量跨度）⭐ 推荐

### 方案描述
- **分级依据**: 纯重量分级，50g跨度
- **数据来源**: 精确称重数据
- **样本量**: 约400个（第二批采样）

### 分级规则
```
Level 1: 500-550g (50g跨度)
Level 2: 450-500g (50g跨度)
Level 3: 400-450g (50g跨度)
Level 4: 350-400g (50g跨度)
Level 5: 300-350g (50g跨度)
Level 6: 250-300g (50g跨度)
Level 7: 150-250g (100g跨度，小型土豆精度要求低)
NG: <150g 或 有缺陷 或 畸形
```

### 优势
✓ **标准清晰**: 等跨度易于理解和实施  
✓ **符合市场标准**: 50g跨度是行业常用规格  
✓ **视觉可区分性好**: 50g差异在相机下可识别  
✓ **客户接受度高**: 与销售包装规格对应  
✓ **实施成本低**: 仅需视觉估重，无需额外传感器

### 潜在问题与解决方案

#### 问题1: 150-200g 与 200-250g 视觉相似
**分析**:
- Level 7 合并为 150-250g，避免此问题
- 小型土豆市场价值较低，精度要求不高
- 客户可接受合并方案

#### 问题2: 密度差异影响
**分析**:
- 土豆密度: 1.05-1.15 g/cm³（品种/含水量差异）
- 500g土豆体积差: 435-476 cm³（9%差异）
- 相机误判风险: 高密度Level 2 可能被识别为 Level 3

**解决方案**:

## 风险评估与应对

### 风险1: 客户不接受方案C
**概率**: 低  
**影响**: 高  
**应对**:
- 准备方案C改进版（Level 7 拆分为 150-200, 200-250）
- 强调50g跨度是行业标准
- 展示数据支持的可行性

### 风险2: 边界样本误判率高
**概率**: 中  
**影响**: 中  
**应对**:
- 实施边界模糊化策略（±5g缓冲区）
- 多角度/多帧验证
- 人工复核机制

**概率**: 中  
**影响**: 中  
**应对**:
- 密度校准算法

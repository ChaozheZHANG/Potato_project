### 第三部分: 三种方案对比（4页）

#### Slide 8: 方案A - Excel方案（重量+尺寸）
```
方案描述
• 分级依据: 重量 + 长度/直径双标准
• 数据来源: 现场实测Excel表格

优势 ✓
• 准确性高（双维度验证）
• 与人工经验一致

劣势 ✗
• 需要双传感器（成本高）
• 尺寸测量误差大（不规则形状）
• 处理时间长（影响节拍）
• 尺寸与重量不完全对应

数据分析
级间重叠率: 12-15%（较高）
视觉可区分性: ⭐⭐
实施难度: ⭐⭐⭐⭐（复杂）
```

#### Slide 9: 方案B - 第一批方案（体积估算）
```
方案描述
• 分级依据: 视觉估算体积
• 数据来源: 人工经验划分

优势 ✓
• 实施简单
• 符合直觉

劣势 ✗
❌ 关键问题: 同一级内重量跨多级
   例: Level 3包含280-520g（跨5级！）
❌ 与客户重量标准严重不符
❌ 训练数据标注混乱

数据分析
级间重叠率: 40-60%（不可接受）
重量跨度: 平均200g/级（太大）

结论: ❌ 此方案不可用
```

#### Slide 13: 潜在问题与解决方案
```
问题1: 密度差异影响
问题: 高密度土豆可能被判低一级
解决: 
  ✓ 密度校准算法（基于形状特征）
  ✓ 圆形度→高密度，椭圆→低密度
  ✓ 误差控制在±5%

问题2: 边界样本误判
问题: 249g vs 251g难区分
解决:
  ✓ 边界模糊化（±5g缓冲区）
  ✓ 多角度/多帧验证
  ✓ 人工复核机制（可选）

问题3: Level 7跨度大
问题: 150-250g是否太宽？
解决:
  ✓ 小型土豆市场价值低，精度要求不高
  ✓ 客户可选择拆分（150-200, 200-250）
  ✓ 灵活配置
```

#### Slide 14: 技术实现方案
```
视觉估重流程
1. 图像采集 → 高分辨率相机
2. 土豆分割 → 精确提取轮廓
3. 特征提取 → 面积、周长、长短轴
4. 重量估算 → 回归模型（相关性0.94）
5. 密度校准 → 形状特征修正
6. 分级输出 → 7+1通道信号

准确率保障
• 训练数据: 2000+标注样本
• 模型类型: YOLOv8 + 回归头
• 验证方法: 实物测试100个样本
• 目标准确率: ≥90%
```

#### Slide 21: Q&A
```
常见问题

Q1: 为什么不用称重传感器？
A: 成本高、影响节拍、维护复杂。视觉估重准确率可达90%+。

Q2: 如果客户要求更高精度怎么办？
A: 可以缩小重量跨度（如25g）或增加验证环节。

Q3: 不同品种土豆密度差异大怎么办？
A: 密度校准算法可以处理，必要时为特定品种重新校准。

Q4: 如何保证NG品不流出？
A: NG召回率目标≥98%，宁可误判OK为NG，不让NG流出。

Q5: 系统部署需要多久？
A: 预计11月底完成部署和验收（6周总工期）。
```

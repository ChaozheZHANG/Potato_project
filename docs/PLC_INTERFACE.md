# PLC 接口对接技术文档

**目标受众**: 传感器/PLC开发人员  
**用途**: 明确数据格式、通信协议、信号映射关系

---

## 1. 系统概述

马铃薯分级系统输出8路数字信号，控制8个物理出料通道：
- **通道1-7**: OK产品，按尺寸分级（S1-S7）
- **通道8**: NG产品，筛选通道

---

## 2. 信号定义

### 2.1 8位数字信号

| 位序号 | 位名 | 分级 | 物理通道 | 激活条件 |
|--------|------|------|----------|----------|
| Bit 0 | L1 | OK_S1 | 通道1 | 最小尺寸合格品 |
| Bit 1 | L2 | OK_S2 | 通道2 | 尺寸2合格品 |
| Bit 2 | L3 | OK_S3 | 通道3 | 尺寸3合格品 |
| Bit 3 | L4 | OK_S4 | 通道4 | 尺寸4合格品 |
| Bit 4 | L5 | OK_S5 | 通道5 | 尺寸5合格品 |
| Bit 5 | L6 | OK_S6 | 通道6 | 尺寸6合格品 |
| Bit 6 | L7 | OK_S7 | 通道7 | 最大尺寸合格品 |
| Bit 7 | NG | NG | 通道8 | 不合格品 |

### 2.2 信号特征

- **互斥性**: 同一时刻只有一个位为 `1`（one-hot编码）
- **默认状态**: 所有位为 `0`
- **持续时间**: 每个信号持续时间由产线速度决定，系统每帧输出一次

## 3. 通信接口选项

### 选项A: Modbus/TCP

#### 协议参数
- **协议**: Modbus TCP/IP
- **功能码**: 05 (写单个线圈) 或 15 (写多个线圈)
- **传输层**: TCP/IP
- **默认端口**: 502

#### 寄存器映射

**方式1: 线圈（Coils）**
- 起始地址：可配置（建议：100）
- 地址范围：`base_address` 到 `base_address + 7`
- 数据类型：布尔（0/1）

**示例映射表**（base_address = 100）：
| PLC地址 | 位名 | 分级 | 物理通道 |
|---------|------|------|----------|
| 100 | L1 | OK_S1 | 通道1 |
| 101 | L2 | OK_S2 | 通道2 |
| 102 | L3 | OK_S3 | 通道3 |
| 103 | L4 | OK_S4 | 通道4 |
| 104 | L5 | OK_S5 | 通道5 |
| 105 | L6 | OK_S6 | 通道6 |
| 106 | L7 | OK_S7 | 通道7 |
| 107 | NG | NG | 通道8 |

**方式2: 保持寄存器（Holding Registers）**
- 如果PLC仅支持寄存器，可将8位打包为1个16位寄存器
- 地址：`base_address`（如200）
- 值：0-255（8位二进制转十进制）

#### 通信流程
1. 系统检测到马铃薯
2. 计算分级结果（OK_S1 到 OK_S7 或 NG）
3. 生成8位信号
4. 通过Modbus/TCP写入对应PLC地址
5. PLC读取信号，控制对应出料道电磁阀/气缸

#### 接线示例
```
视觉系统 (PC) ←以太网→ PLC (192.168.1.100:502)
                              ↓
                        输出模块
                              ↓
                      [通道1-8电磁阀]
```

---

### 选项B: 串口 RS232/485

#### 协议参数
- **接口**: RS232 或 RS485（可配置）
- **波特率**: 9600（可配置）
- **数据位**: 8
- **停止位**: 1
- **校验**: 无
- **流控**: 无

#### 数据格式

**ASCII文本格式**：
```
<bit0>,<bit1>,<bit2>,<bit3>,<bit4>,<bit5>,<bit6>,<bit7>\r\n
```

**示例**：
- `OK_S3`: `0,0,1,0,0,0,0,0\r\n`
- `NG`: `0,0,0,0,0,0,0,1\r\n`
- 默认：`0,0,0,0,0,0,0,0\r\n`

**二进制格式**（可选）：
- 发送单字节：值 0-255（8位直接映射）
- 示例：`OK_S3` → 字节值 `4` (二进制 `00000100`)

#### 通信流程
1. 系统检测完成
2. 格式化8位数据为ASCII或二进制
3. 通过串口发送
4. PLC串口模块接收并解析
5. PLC控制对应输出通道

#### 接线示例（RS485）
```
视觉系统 (PC) ←RS485 (A/B/GND)→ PLC串口模块
                                        ↓
                                   输出模块
                                        ↓
                                [通道1-8电磁阀]
```

## 4. 时序要求

### 4.1 信号更新频率
- **视频流模式**: 每帧一次（取决于摄像头帧率，如30fps）
- **批量模式**: 每张图片一次
- **最小间隔**: 建议 ≥ 50ms（避免PLC响应不及）

### 4.2 信号保持时间
- **建议**: 根据传送带速度计算
- **示例**: 传送带速度 0.5m/s，出料道间距 0.1m → 需要保持 ≥ 200ms

### 4.3 时序图示例

```
时间轴 →
[检测中] [计算] [发送信号] [保持] [复位] [下一帧]
  100ms   50ms    10ms      200ms   10ms
```

## 5. 接口对接步骤

### 步骤1: 确认物理接线
- [ ] 确认8个输出通道的物理接线顺序
- [ ] 确认通道1-7为OK出料道，通道8为NG筛选道
- [ ] 确认PLC输入模块型号和地址范围

### 步骤2: 选择通信方式
- [ ] Modbus/TCP：确认PLC IP、端口、寄存器地址
- [ ] 串口：确认串口号、波特率、数据格式

### 步骤3: 配置系统参数

**Modbus/TCP配置**：
```bash
python3 scripts/grade_potato.py \
  --plc modbus \
  --modbus_host 192.168.1.100 \
  --modbus_port 502 \
  --modbus_address 100
```

**串口配置**：
```bash
python3 scripts/grade_potato.py \
  --plc serial \
  --serial_port /dev/ttyUSB0 \
  --serial_baud 9600
```

### 步骤4: 测试通信
1. 运行调试模式（`--plc print`），查看输出信号
2. 使用测试脚本单独发送信号
3. 验证PLC接收并正确触发对应通道

### 步骤5: 联调
1. 使用真实图片测试
2. 验证信号时序
3. 调整保持时间和复位时间

## 6. 故障排查

### 问题1: PLC未接收到信号
- **检查**: 网络/串口连接是否正常
- **检查**: PLC地址/端口是否正确
- **检查**: 防火墙是否阻止连接

### 问题2: 信号映射错误
- **检查**: `grading_rules.json` 中的信号映射表
- **检查**: PLC地址映射是否与配置一致

### 问题3: 信号延迟
- **优化**: 使用更快的通信方式（Modbus TCP通常快于串口）
- **优化**: 减少数据处理时间
